# Notice

This repository includes public-sector geospatial data from external sources.

## DC No Fly Zones

The included `data/us/dc/no-fly-zones-p56.geojson` file is derived from the No Fly Zones GeoJSON dataset distributed through data.gov and ArcGIS Hub. data.gov lists the resource license as Creative Commons Attribution.

The source abstract states that the dataset contains P56A and P56B flight restrictions in the District of Columbia and identifies the National Geospatial-Intelligence Agency as the dataset provider.

Users are responsible for complying with the original data license and for verifying airspace data against current official sources.
