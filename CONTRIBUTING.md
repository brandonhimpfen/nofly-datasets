# Contributing

Contributions are welcome when they improve data quality, coverage, loaders, validation, or documentation.

## Dataset requirements

New datasets must:

1. Use real source data only.
2. Include source attribution and retrieval date.
3. Preserve the original license or usage terms.
4. Be valid GeoJSON.
5. Avoid legal or operational claims that exceed the source data.

Large datasets should generally be added through loaders instead of committed directly.
