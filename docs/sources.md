# Sources

## DC No Fly Zones, P-56A and P-56B

- Dataset: No Fly Zones
- Publisher: District of Columbia
- Source agency noted in abstract: National Geospatial-Intelligence Agency
- Distribution: data.gov / ArcGIS Hub
- Format used: GeoJSON
- License listed by data.gov: Creative Commons Attribution
- Included file: `data/us/dc/no-fly-zones-p56.geojson`
- Retrieved: 2026-05-02

The dataset contains P-56A and P-56B restricted flight areas in Washington, DC.

## FAA UAS Facility Map Data

- Publisher: Federal Aviation Administration
- Distribution: FAA UAS Data Delivery System / ArcGIS FeatureServer
- Supported query format: GeoJSON
- Feature layer geometry type: Polygon
- Estimated layer count at source review: 378,411 features
- Loader: `nofly_datasets.faa_uas_facility_map`

The FAA describes UAS Facility Maps as maximum altitudes around airports where the FAA may authorize Part 107 operations without additional safety analysis. These are not equivalent to a universal no-fly dataset, but they are an important UAS airspace authorization layer.
